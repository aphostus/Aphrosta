## Overview

**Aphrosta** is the flagship agent of **Aphostus**, a private proving ground where new AI system concepts are designed, stress-tested, and refined. It is built as a *virtual robotic agent*: not a single chatbot, but a layered agentic system whose long-term vision is to unite the strengths of every agent in the world into one coherent intelligence.

Aphrosta is shaped by the **Metanist** identity and its central idea, **Curation**: knowing *what* to remember, *how* to remember it, *when* to bring it back, and when to let it go. Where most assistants simply respond, Aphrosta curates context, memory, and tools around the person it serves.

The name **Agenta** is a term coined by Aphostus to separate this class of system from the ordinary agents of the current era, marking a step toward the next generation of technology.

## Armouras

Aphrosta extends itself through **Armouras** (*Armours*): modular layers of capability that equip the agent with ideas not found in conventional agents. Each Armoura adds a new strength to the core without changing what the core is, allowing the system to adapt, specialize, and evolve as new concepts mature.

## Capability Systems

Aphrosta is organized into ten core systems, each responsible for one dimension of agent behavior.

| Code | System | Version | Role |
|------|--------|---------|------|
| **LMS** | Language Modeling System | V.01 | Automatically selects the most suitable language model for the context and need, balancing efficiency and quality. |
| **CTS** | Conditional Trigger System | V.01 | Governs input and output triggers with Passive and Assertive modes across different environments. |
| **MDS** | Memory Database System | V.01 | Extends context through single-chat, multi-chat, and project-level memory, with both short-term and long-term retention. |
| **COS** | Central Operating System | V.01 | Runs reasoning loops, function calling, and tool activation and deactivation, along with decisions and operations. |
| **DMS** | Dimensional Memory System | V.01 | Handles data dimensionally, mapping useful relations between pieces of information and grounded in practical use over theory. |
| **PCS** | Persona Configury System | V.01 | Shapes the vibe, strength, and personality of the agent through careful, experimental tuning. |
| **SLS** | State Logtracker System | V.01 | Keeps a running log of what has happened, what is happening, and what is about to happen. |
| **SPS** | Security Protocol System | V.01 | Applies custom security principles to the agent, with further hardening at the owner's discretion. |
| **BTS** | Bodyset Tailorship System | V.01 | Gives the agent a body of skills and tools, with the language model acting as its central processor. |
| **GSS** | Group Swarm System | V.01 | Uses cloning frameworks to multitask and extend effective token capacity. |

## The Experience

Aphrosta is designed as a single, immersive workspace. Its interface is **monochrome by default**: pure black and white, soft frosted-glass surfaces, hairline borders, and gentle ambient gradients that let the content take focus. Motion uses spring and smooth easing curves so every transition feels fluid and deliberate, and a pulsing icon loader opens the experience.

### Workspace

- **Sessions**: Start, search, and revisit conversations from a persistent sidebar, with up to three pinned sessions kept within reach.
- **Worlds**: Dedicated spaces for projects and their accumulated context.
- **Agents**: A home for agentic behavior and its configuration.
- **Data**: Direct visibility into what the agent holds in memory.
- **Automation**: Build flows and routines.
- **Connectors**: Link apps and data to the agent.

### The Composer

The message composer is the heart of the interface. It features:

- An **Agent toggle** that switches the system between conversational and agentic operation, with play and pause control.
- **Live word-state highlighting** while typing.
- A **token meter** that stays visible in the idle ring.
- **Text and voice modes** with an animated waveform.
- **File and image attachments** for code, documents, data, and visuals.
- A collapsible **Thought panel** that reveals the agent's reasoning as it works.

### Living States

Aphrosta communicates what it is doing in real time, cycling through expressive states: *Thinking, Planning, Recalling, Searching, Reasoning, Analyzing, Composing, Curating, Musing,* and *Finalizing*. **Curating** reflects the Metanist identity at the center of the system.

## Models and Effort

Aphrosta is model-agnostic. A single interface connects to eight leading providers, each with its own identity color and a rich catalog of current models:

| Provider | Provider | Provider | Provider |
|:--------:|:--------:|:--------:|:--------:|
| **Claude** | **ChatGPT** | **Gemini** | **Grok** |
| **DeepSeek** | **Groq** | **Kimi** | **Perplexity** |

Models can be switched at any moment from the top bar, and the **Effort** control tunes how deeply the agent reasons:

| Level | Character |
|-------|-----------|
| **Minima** | Fastest, lightest reasoning |
| **Low** | Quick and efficient |
| **Medium** | Balanced and preferred |
| **High** | Deeper deliberation |
| **Maxima** | Maximum reasoning depth |

Aphrosta also tracks **usage across every model together**, presenting a daily token total broken down by provider, with an optional configurable limit and reset timer.

## Memory and Context

Memory is where Curation becomes tangible. Aphrosta separates **short-term** and **long-term** memory, supports persistent memory notes, and lets the person decide how much context the agent carries forward. Sessions are saved, searchable, pinnable, and regenerable, so ideas are never lost and any response can be revisited and refined.

## Privacy and Control

- **Account sync** through Google sign-in, with settings and sessions kept consistent across devices.
- **Local-first behavior** with offline-capable persistence.
- **Privacy masking** for sensitive details like email and phone number.
- **Granular permissions** for device capabilities, reviewed from a single list.
- **Device management** showing where the account is active.
- **Full data export** for portability and ownership.
- **Usage and training preferences** that remain in the owner's hands.
