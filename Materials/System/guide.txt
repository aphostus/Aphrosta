=== APHROSTA DEV GUIDE ===

--- 1. START HERE (Every time) ---
cd /sdcard/Programs/Aphrosta/Website

--- 2. AI VIBECODING (vibe.py) ---
The script lives at Operators/Configury/vibe.py

A. GENERATE CODE (AI Mode)
python Operators/Configury/vibe.py <file> '<instruction>'
Example: python Operators/Configury/vibe.py script.js 'Fix the timer bug'

B. APPLY PLANNER.TXT (Direct Mode - No API limits)
python Operators/Configury/vibe.py <file> planner.txt --direct

C. SAVE DIRECTLY TO ORIGINAL (Skip the Prototypes folder)
Add --inplace to any command. It backs up the old file automatically.
Example: python Operators/Configury/vibe.py script.js planner.txt --direct --inplace

D. TEST FIRST (Dry Run - see if it works without writing)
Add --dry to any command.

--- 3. FILE MANAGEMENT BASH ---
- See files in current folder: ls
- View a file's content: cat <file> (e.g., cat script.js)
- View the last 20 lines of an error: tail -n 20 <file>
- Copy a file: cp <source> <destination>
- Move/Overwrite a file: mv <source> <destination>
  (Use this for: mv Prototypes/NEW_script.js script.js)
- Delete a file: rm <file>
- Clear the screen: clear

--- 4. CHUNK WORKFLOW (For massive script.js) ---
1. Find the chunk: cat Materials/System/js_map.txt
2. Edit chunk: python Operators/Configury/vibe.py Materials/Private/sources/src_js/chunk_015.js 'fix bug' --inplace
3. Rebuild script.js: cat Materials/Private/sources/src_js/chunk_*.js > script.js

--- 5. GIT / GITHUB ---
- Save all changes: git add .
- Commit with a message: git commit -m "update"
- Upload to GitHub: git push origin main
- Download from Github: git pull
- Undo ALL uncommitted changes: git restore .
- Check status: git status

--- 6. PREVIEW WEBSITE (Vite) ---
Note: Vite runs in the Termux hidden folder, not /sdcard/
cd ~/Website
npx vite --port 3000 --host
(Stop server: Ctrl + C)
